Hard Cases Testing Suite (Screening Verification)

IncuBrix handles edge cases gracefully, reporting explicit warnings or structured error codes instead of failing silently or producing corrupted audio. Test each scenario live below:

⏱️ 1. Very Short & Very Long Tracks
Tests boundary duration enforcement (within 0.05s) with purposeful cadence fade (no hard cuts), and boundary validation for out-of-range requests (<5s or >300s).
Sensible Handling: 5.0s ends with musical barline fade; 300.0s maintains tempo/key; <5s rejected cleanly with HTTP 400.
☯️ 2. Vague or Contradictory Prompts
Prompts with opposing emotional polarity like "calm but aggressive" or nonsensical strings like "fast slow loud quiet happy sad".
Sensible Handling: Detects semantic contradiction and resolves dynamically into a peaceful harmonic intro building into an aggressive driving groove, with an explicit warning.
🎤 3. Real Artist, Song, or Vocal Requests
Prompts referencing protected artists (e.g. "Queen", "Drake"), copyrighted songs ("Bohemian Rhapsody"), or asking for "singing vocals".
Sensible Handling: Remains 100% instrumental, suppresses vocals, generates an original composition to prevent copyright infringement, and explicitly notifies user.
📐 4. Section Closely Spaced / Out-of-Bounds
Sections scheduled <1.5s apart (e.g. 0.8s, 1.4s), or a section timestamp starting after the track duration has already ended (15s in 10s track).
Sensible Handling: Close sections are smoothed to beat grid with a warning; section exceeding duration is rejected with HTTP 400 VALIDATION_ERROR.
🤫 5. Narration with No Speech / Long Silence
Narration audio file submitted contains zero voice activity (pure background room tone or silence), or long pauses between sentences.
Sensible Handling: Speech envelope follower detects no speech, bypasses ducking attenuation leaving mix unattenuated, and logs explanatory note in manifest.
🌐 6. Non-English Multilingual Prompts
Prompts written in Spanish, German, French, or Japanese without English translation.
Sensible Handling: Multilingual semantic parser translates keywords (e.g. "Musica alegre") and maps them to appropriate genre and instrumentation, with notification.
⚡ 7. Simultaneous Jobs & Idempotency Conflicts
Two simultaneous jobs sent in the same millisecond; duplicate submission with same Idempotency-Key; or same key with conflicting payload.
Sensible Handling: Concurrent jobs queue safely; duplicate submission returns existing job (202); conflicting payload returns HTTP 409 Conflict.
🛡️ 8. Provider Failure / Timeout Recovery
Upstream AI model or music provider crashes or times out in the middle of processing a job.
Sensible Handling: Worker pipeline catches timeout and runtime failures, transitions job status to failed with structured error code and retryable: true. Never hangs indefinitely.
